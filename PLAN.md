MEJORAS POR HACER
- Falta la logica del mensaje de wats o de correo, se puede crear un ticket automaticamente con la funcion ya establecida o se manda un mensaje por medio de correo o de whatsApp a un tecnico para saber del problema
	Aqui se tiene que hacer esta logica de correo o mesnaje de texto, se hace que se mande de un correo tipo bot o de u numero de la empresa para que lleguen a un chat concreto de un numero ya conocido
	Este metodo de contacto se puede cambiar en el .env para la preferencia de la empresa
